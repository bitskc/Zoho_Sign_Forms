## Long description

**Stop sending. Start collecting.**

Zoho Sign is built for one-to-one requests: you pick a recipient, you send, they sign. But some documents shouldn't need a sender at all — waivers, intake forms, client agreements, W-9s, onboarding paperwork. SignFlow Pro turns any Zoho Sign template into a **permanent, self-serve signing link** that anyone can open and sign.

**How it works**
1. Connect your Zoho Sign account via API (credentials encrypted at rest)
2. Pick a template and which signer role the public link fills
3. Share your permanent URL — or its print-ready QR code

Signers enter their name and email on a branded landing page and sign through Zoho Sign's standard flow. No Zoho account, no app download. Completed documents land in your Zoho Sign account with the usual certificate and audit trail.

**Features**
- **Permanent links** — one URL per template, never expires, never needs re-sending
- **Print-ready QR codes** — with stable redirect IDs, so printed signage keeps working even if you rename the form
- **Branded landing pages** — your logo, colors, and copy
- **Analytics** — visits, submissions, and conversion rate per form
- **Embeddable signing pages** — put the signing flow directly on your website
- **Multi-role templates** — the public link fills one role; remaining roles route by email automatically
- **Works with any Zoho Sign plan that has API access** — no Enterprise upgrade required

**Pricing**
$60/year flat. No per-user fees. You pay Zoho's standard API rate ($0.50/document sent) directly to Zoho.

**Security**
Your API credentials are encrypted. SignFlow Pro never stores or accesses your signed documents — all signing happens through Zoho Sign's own platform.

## Reviewer notes (for Zoho's marketplace review team)
SignFlow Pro uses the Zoho Sign REST API with customer-supplied OAuth client credentials. It creates envelopes from the customer's own templates and does not read or store signed documents. Data stored: form configuration, landing-page customization, and aggregate analytics events.
